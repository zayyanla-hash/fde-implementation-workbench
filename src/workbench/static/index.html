01

Customer intake

Start with CSV or a JSON array.

Required fields & format

Each customer needs all seven fields. Owner fields must be email addresses. Customer IDs use lowercase letters, numbers, underscores or hyphens, up to 64 characters.

customer_id, customer_name, integration, technical_owner, data_access_owner, launch_owner, acceptance_criteria

CSV includes a header row. JSON is an array of objects. Unknown fields, conflicting IDs and malformed source are reported. Imports with errors are not saved.
